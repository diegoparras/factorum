Factorum

Inicio

Cómo viene todo, de un vistazo.

Revisar

Lo que Factorum no pudo dar por bueno solo. Abrí uno y usá el teclado: A aprobar y seguir, J siguiente, K anterior, Esc cerrar.

Correo retenido

Mails con facturas de remitentes que no están entre los permitidos. Factorum no los procesó ni les contestó. Aceptá los que sean de confianza (y, si querés, sumá al remitente) o descartalos. Se borran solos a los 30 días. Nunca se guarda el texto del mail: solo quién, el asunto y los adjuntos.

Verificar una factura o un ticket

Subí el PDF o la foto y Factorum te dice si es legal: lee el QR y el texto, controla las sumas y, con Arcanum, la constata con ARCA (WSCDC) y busca al emisor en la base de apócrifos. Los tickets de controlador fiscal no se constatan: se controla el CUIT y la base de apócrifos. No se guarda nada.

Cargar facturas

PDFs, fotos o un ZIP con cientos de facturas o tickets de compra. Se procesan en segundo plano: podés seguir trabajando.

Lotes

Cada carga (web, chat, MCP o Arcanum) es un lote. Tocá uno para ver sus comprobantes. Si cargaste algo mal, podés cambiarle el cliente o mandarlo a la papelera.

Comprobantes

Resumen

Por alícuota y por rubro, con los filtros de Comprobantes (elegí «Solo tickets» para ver los gastos con ticket). Las notas de crédito restan; lo que está en moneda extranjera no se suma.

Conciliación

Cruzá las facturas de compra que cargaste de un cliente con lo que ARCA dice que recibió (Mis Comprobantes, que baja Arcanum): qué coincide, qué tiene diferencias, qué falta pedirle al cliente y qué no figura en ARCA.

Libro IVA Digital

Exportá las compras de un cliente en un mes con el formato de importación del Libro IVA Digital de ARCA: el archivo de comprobantes y el de alícuotas, listos para «Importar archivos» en Libro IVA Compras. Antes de bajarlos, mirá los problemas.

Papelera

Lo que se borró de tus clientes. Se puede restaurar tal cual estaba (con sus estados y correcciones) hasta que se borra para siempre.

Configuración

Todo lo que antes iba en variables de entorno. Lo que fija el servidor gana y aparece bloqueado. Al guardar, se aplica sin reiniciar.

Usuarios

Quién entra a Factorum, con qué rol y a qué clientes. Al crear a alguien, con el correo saliente configurado, Factorum le manda una invitación por mail para que elija su contraseña; si no, genera una temporal que se muestra una sola vez y obliga a cambiarla al entrar.

Claves de API

Para la API REST, MCP (asistentes) y las otras apps de la suite. La clave se muestra una sola vez: guardala en un lugar seguro.

Conectar

Factorum se puede usar desde otros programas: la API REST para integraciones y MCP para asistentes como Claude.

Auditoría

Quién hizo qué y cuándo: entradas, usuarios, claves, configuración, correcciones, aprobaciones, exportaciones y pases de la suite. Nunca guarda contraseñas, claves ni tokens.
